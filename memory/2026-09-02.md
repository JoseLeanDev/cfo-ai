### Frontend Build Note
- Build command: `cd frontend && npm run build`
- Dist folder: `frontend/dist/`
- Render sirve `frontend/dist/` como static site
- El archivo `index.html` en `dist/` referencia el bundle JS con hash (ej: `index-DJfv2zbw.js`)
- **Siempre** hacer `npm run build` después de cambios en frontend antes de commit/push

### Browser Cache Issue
- El navegador puede cachear el bundle JS viejo (`index-2FTEsrhJ.js`) incluso cuando el HTML ya apunta al nuevo (`index-DJfv2zbw.js`)
- Para verificar fixes, usar URL con `?nocache=...` o abrir nueva pestaña
